# Rank Basics

Ranks describe how powerful an essence user is and how they are viewed by the wider world.

This file only includes rank information the players currently need. Higher-rank mechanical details are intentionally omitted until the party learns them in play.

## Rank Table

| Rank | D&D Levels | General Meaning |
|---|---|---|
| Normal | No D&D level range | Someone with less than two essences. |
| Iron | Levels 1-4 | New or local adventurers. |
| Bronze | Levels 5-8 | Established adventurers. |
| Silver | Levels 9-12 | Regionally powerful figures. |
| Gold | Levels 13-16 | National-level powers. |
| Diamond | Levels 17-20 | Legendary figures. |

## Low, Mid, and High Rank

Each main rank covers four D&D levels.

| Rank Band | Meaning |
|---|---|
| Low | The lowest level of that rank. |
| Mid | The middle levels of that rank. |
| High | The highest level of that rank. |
